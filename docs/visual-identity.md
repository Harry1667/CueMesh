# CueMesh 視覺規範

網站與擴充功能共用同一套外觀，要讓人一眼認得是同一個產品。這份文件只規範外觀，功能以實際介面為準。

## 整體感覺

冷靜、精準、簡約、專業，近似 Apple 的克制：清楚的字體、足夠的留白、刻意的對齊、極少的視覺雜訊。識別元素是深海軍藍文字、鈷藍動作色、淡薰衣草點綴，以及乾淨的白色表面。

## 字體

系統無襯線字體：Apple 系統字體，Windows 用 Segoe UI，備援 Noto Sans、Arial。內文一般字重，標題 medium 或 semibold，按鈕 medium。標題字距略緊，內文好讀。等寬字只用於少量技術標籤。

擴充功能建議尺寸：

| 用途 | 尺寸 |
|---|---|
| 主標題 | 22–28px |
| 區段標題 | 16–20px |
| 內文 | 13–14px |
| 輔助文字 | 11–12px |

英文與繁體中文都要維持清楚的層次與舒適的間距。

## 版面與間距

簡單對齊的區段，清楚的標題與細分隔線，可讀的列與開闊的留白。淡色面板只用來把相關資訊分組。

| 擴充功能 | 建議值 |
|---|---|
| 外距 | 16–20px |
| 相關元素間距 | 8–12px |
| 區段間距 | 20–28px |

## 形狀與表面

- 按鈕與輸入框約 6px 圓角，小面板約 6–8px，邊框細而低調。
- 一般表面保持平面；柔和陰影只用於浮動選單與對話框；避免多層巢狀卡片。

## 按鈕與選取

- **主要按鈕：** 實心鈷藍、白字、6px 圓角。
- **次要按鈕：** 白底或透明、細邊框、海軍藍字。
- **低調動作：** 純文字加小型線條圖示或箭頭。
- 網站主要按鈕約 46px 高，精簡控制項可以小一點，但要好操作。
- 選取的導覽用細藍底線或淡薰衣草底色；鍵盤焦點要清楚可見。

## 圖示與品牌

- 統一使用 Lucide 風格線條圖示，通常 16–20px，視覺上次於內容。
- 名稱固定為 `CueMesh`。
- Logo 為單色：四個相連的圓角方塊，略微逆時針傾斜，右上方塊偏移，中央留白。

## 動態與細節

- 控制項回饋約 150ms，面板轉場約 240ms，並尊重「減少動態」偏好。
- 不用裝飾性彈跳、發光、漸層背景、玻璃面板、超大膠囊形狀、過多陰影與表情符號裝飾。
- 標籤精簡，輔助文字有用。
