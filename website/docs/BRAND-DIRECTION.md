# CueMesh selected brand direction

Selected by the user on November 7, 2026. This selection replaces the three generated logo explorations as the implementation direction.

## Logo

Use the four connected rounded tiles in the supplied reference. Preserve the slight counterclockwise tilt, the offset upper-right tile, the thin connections, and the open space at the center. The mark represents distinct contributors sharing one context.

The reference matches the existing header's CSS mark. The SVG assets below are a scalable adaptation of that existing code-native design, not an enlargement or image-generated alteration of the small supplied bitmap. The original bitmap is preserved as a reference.

- `public/brand/cuemesh-mark-graphite.svg`: dark mark for light surfaces, transparent background.
- `public/brand/cuemesh-mark-light.svg`: pale mark for dark surfaces, transparent background.
- `public/brand/cuemesh-icon.svg`: pale mark inside a deep charcoal rounded square, suitable as the favicon source.
- `public/brand/selected-logo-reference.png`: unchanged user-supplied reference.

Keep the logo monochrome. Use the accent around selected states and calls to action. Retain the exact wordmark spelling **CueMesh** and the website's system sans-serif family. Do not adopt a generated C/M monogram, woven M, or speech-bracket mark.

## Palette

| Role            | Color     | Use                                                |
| --------------- | --------- | -------------------------------------------------- |
| Cloud           | `#F6F5FA` | Main light canvas                                  |
| White           | `#FFFFFF` | Content and elevated surfaces                      |
| Midnight        | `#151C33` | Primary text, light-mode logo, dark buttons        |
| Deep charcoal   | `#0B1021` | Dark product sections and icon background          |
| Lilac           | `#B5A5EF` | Restrained accent, selection, dark-surface action  |
| Cobalt          | `#3659F5` | Accent text and focus indicators on light surfaces |
| Muted           | `#626A80` | Secondary text on light surfaces                   |
| Divider         | `#DEE0EB` | Quiet borders                                      |
| Pale foreground | `#F6F5FA` | Logo and text on dark surfaces                     |

Use midnight text on lilac. Use pale foreground on deep charcoal and white on cobalt. Lilac is a surface/accent color, not small text on white. Keep most of each page neutral, with color concentrated around meaningful actions or selected information. Retain semantic red/amber colors for errors and warnings.

In existing styles, `--lime` and `--lime-hover` may temporarily remain compatibility names while their values change to lilac; recommended hover `#A795E6`. Update both light and dark styles and any hard-coded citron values. Keep dark-mode secondary text sufficiently light; the light-mode muted color is not intended for dark surfaces.

## Apple-inspired presentation

The user chose Apple's MacBook Pro display page as a direction in the website chat. Interpret this through centered large type, generous negative space, clear product storytelling, carefully paced sticky scenes, and smooth native scrolling. Retain CueMesh's own logo, colors, copy, and product imagery.

Use the operating system's font stack, concise headings, subtle separators, and restrained corner radii. Keep motion tied to understanding: selected context becomes a shared brief, responsibilities separate, and results reconnect. Honor reduced-motion preferences and keep all content available without animation.

The working page should remain a professional tool: compact navigation, clear state hierarchy, readable task ownership and progress, orderly panels, and restrained animation. Preserve responsive layouts, keyboard focus, and the existing language/theme preferences.
